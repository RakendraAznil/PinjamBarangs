# PinjamBarangs
Aplikasi yang membantu mahasiswa untuk peminjaman barang yang bisa dilakukan oleh mahasiswa ataupun non mahasiswa. Melalui aplikasi ini, pengguna dapat mencari barang yang sedang dibutuhkan atau menawarkan barang yang dimiliki untuk dipinjamkan, seperti tripod, proyektor, Sound System, Microphone, Alat Praktikum dan lain-lain
